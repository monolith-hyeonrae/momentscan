## E003 — select v2: 방향 있는 읽기 + 대조(Δ) 항 + 악구 세그먼트  · 2026-06-11

- **임팩트 이론** (사용자, 2026-06): 임팩트 = ① 상태의 **대조**(표정·포즈·조명의
  변화) ② **강한 방향 있는 상태**(즐거움·호기심·환호성) ③ **맥락적 세렌디피티**
  (머리카락 날림, 뒤따르는 카트, 풍력발전소·구름, 태양 스침, 인터랙션).
  현재 차원은 전부 순간 상태 — Δ축과 장면 맥락 축이 결핍. 조명은 legacy 65D의
  20D가 46D 정리에서 탈락했던 것 — 복원 대상 (dpr_v1.t7 보존됨).
- **가설**: 같은 차원 위에서 읽기를 바꾸면 — appearance_ref(정면 게이트
  |yaw−12°| + 저표정에너지), highlight 2단(WHEN=동작 임팩트+Δ대조,
  WHICH=얼굴 가시성×valence) — cand-vs-RANDOM agreement > 0.5 유의.
  E002와 묶어 "feature가 아니라 reading이 성능을 만든다"의 통제 실험 쌍.
- **구성**: 방향 있는 피크(em_happy/em_surprise) + |Δ상태|(visualbind
  delta_sliding 재사용) + lighting__sector_0..8 9차원 추가(9-구역 밝기,
  픽셀 산수 — Δlighting으로 "태양 스침"의 조잡한 검출).
- **악구 세그먼트** (사용자 음악 은유: 시→도 귀결로 구간 완성): 고정 피크±1.5s
  폐기 → excursion 경계(잔차가 α·MAD baseline을 떠나는 onset → 피크 → 귀결)
  + 비대칭 숨 패딩(전 0.5s/후 1s). rolling-median=으뜸음, 잔차=긴장이라는
  대응이 이미 시스템에 내재 — 세그먼트만 악구 모양으로. 미귀결=강등,
  선행 쉼표 길이=대조 보너스. 검증: 잘린 클립이 "완결"로 느껴지는가.
- **결과** (rescore, 동일 168쌍):

  | | highlight | profile |
  |---|---|---|
  | E001′ (12차원, 무방향) | 0.456 | 0.519 |
  | E002 (23차원, 무방향) | 0.441 | 0.519 |
  | **E003 (55차원, 방향+Δ)** | **0.588** | **0.574** |

- **결론: 가설 지지.** 차원 추가 단독 = −0.015 (E002), 읽기 교체 = **+0.147**
  (E003). "성능은 feature가 아니라 reading에서 온다"의 통제 실험 쌍 완성.
  highlight가 처음으로 0.5를 유의하게 상회 — 방향(valence)·대조(Δ)·가시성이
  사람 선호와 정렬되기 시작. 정성: dual_2 main 대표 프레임이 f502(선라벨
  "머리 쓰다듬는 상호작용 good"의 f500 옆)로 이동, 세그먼트 가변 길이
  (1.8~5.3s 악구) 동작.
- **남은 거리**: 0.588은 시작이지 목표가 아님 — AU 부재(환호 얼굴의 정밀
  부호), 장면 맥락 항 부재(DINO 차선), WHICH의 가시성 항이 조잡(yaw 유무만).

- 이후 예약: E005+ = DPR SH 포팅, DINO 차선(인터랙션·배경 존재감·hair 날림).

## E004 — AU 12차원 포팅 (LibreFace) + 환호 부호  · 2026-06-11

- **가설**: 환호하는 '얼굴'의 정밀 부호(au25/26 입 벌림 + au5 눈 치켜뜸 +
  au1/2 눈썹)가 emotion 프록시를 보강해 highlight WHICH가 개선되고,
  AU 에너지(표정 억제의 직접 측정)가 profile calm을 개선한다.
  범위는 비디오 분석 — 오디오 모달리티 도입 안 함 (사용자 확인).
- **구성**: LibreFace 2단 onnx 포팅(Encoder→Intensity, DISFA 0–5,
  256→center-crop 224, ImageNet norm). 채움 44/55.
  읽기: valence += cheer(5개 AU 평균), calm ×= (1−0.5·au_energy),
  **굴욕사진 게이트**(사용자 통찰): emotion softmax의 max 확률이 낮음 =
  애매한 표정(전이 중 일그러짐) = 사진 활용 불가 → profile·WHICH 양쪽에
  ×(0.4+0.6·em_conf). 분류기의 불확실성 자체가 공짜 품질 신호.
- **포팅 중 발견 2건**: ① legacy는 bbox에 **10% 패딩** 후 crop — 타이트
  crop은 강도를 절반 이하로 깔아뭉갬 (au25 p95 0.12→0.32). ② 그래도
  절대 강도는 0–5 스케일에서 낮게 깔림(작은 야외 얼굴) — legacy 체감
  "성능이 좋다는 느낌은 아니었다"의 재현. 상대 다이내믹(max/mean ~7배)은
  실재하므로 **레지스트리엔 원값, 읽기에서 트랙 내 정규화**로 대응.
- **결과** (rescore, 동일 168쌍):

  | | highlight | profile |
  |---|---|---|
  | E003 | 0.588 | 0.574 |
  | **E004 (+AU·환호 부호·굴욕사진 게이트)** | **0.632** | **0.593** |

- **결론: 가설 지지.** highlight +0.044, profile +0.019. 누적 궤적:
  highlight 0.456 → 0.441 → 0.588 → **0.632** / profile 0.519 → 0.519 →
  0.574 → **0.593**. 무학습(라벨 0개 소비) 읽기 개선만으로 무작위 동급에서
  유의한 사람-선호 정렬까지. AU의 낮은 절대 강도에도 트랙 내 정규화로
  기여 실증 — legacy XGBoost가 절대값을 그대로 먹어야 했던 것과의 구조적
  차이(스케일 문제를 reading 층에서 흡수).
- **다음 후보**: E005 = DINO 차선(장면 맥락 — 임팩트 이론의 ③축, 남은 가장
  큰 결핍) 또는 DPR SH. 앵커 의심 2건(dual_1·test_0) 조사도 미결.

## E005 — 포즈 등급 가시성 (viz가 찾은 결함의 수리)  · 2026-06-11

- **발견** (select_timeline, test_0·dual_3): highlight 대표 프레임(●WHICH)이
  옆얼굴·손 가림에, profile 픽이 고개 숙임에 떨어짐. 코드 원인: ① WHICH
  visibility가 yaw **유무만** 보는 이진 항 (NaN→0.5, 측정되면 60° 돌려도
  무벌점), ② profile 정면 게이트가 yaw만 보고 **pitch 무시**.
- **가설**: 가시성을 포즈 등급으로 (yaw 정면성 연속 게이트, σ=30° — 외형
  레퍼런스보다 관대; NaN=0.25 — 무메시는 대개 강한 돌림/가림), profile에
  pitch 게이트 추가 (경험적 수평 −10°, 코퍼스 중앙값 −9.7°, σ=15°) →
  highlight·profile agreement 모두 상승.
- **결과** (rescore, 동일 168쌍):

  | | highlight | profile |
  |---|---|---|
  | E004 | 0.632 | 0.593 |
  | E005① WHICH yaw 등급 | 0.632 (중립) | — |
  | E005② profile pitch 게이트 | — | **0.556 (악화 → 기각·복원)** |

- **결론: 가설 대부분 기각 — 그리고 그게 수확.**
  - ② pitch 게이트는 측정이 명확히 기각 (0.593→0.556). 해석: 라이딩 자세의
    자연스러운 pitch 분포(IQR −14.5~−3.3°)를 라벨러는 수용 — pitch prior는
    사람 선호와 불일치. 고개 숙임 픽은 눈 가시성(seg_eye, 미포팅) 같은
    직접 신호의 일. **viz가 보여준 결함이 실재해도, 직관적 수리가 측정을
    통과한다는 보장은 없다 — 측정 루프의 존재 이유.**
  - ① yaw 등급은 중립(0.632 동일) + 정성으로도 대표 프레임 거의 불이동.
    원인 진단이 진짜 수확: **Δpose가 WHEN(임팩트)을 만들므로 악구 자체가
    고개 돌림 순간에 형성 → 악구 안에 정면 프레임이 없어 WHICH가 고를 게
    없음.** 프레임 가중치가 아니라 세그먼트 수준 처리(낮은 max-which 악구
    강등, rep 탐색 창 확장)가 필요 — E006 후보. 항은 유지(무해·방향 옳음·
    옆얼굴 악구 점수 디스카운트).
- **앵커 조사 (identity strip + split-half 임베딩)**:
  - test_0 t2 main = 단일 인물 확인 (전/후반 rep cos **0.804**, 옆→정면으로
    돌아본 것; E001의 "f410 행인" 의심은 현 파이프라인 기준 미재현).
    행인 군집(s1, 저신뢰 체인 머지 포함)은 전부 drop — 제품 무영향.
  - **새 발견: test_0 t18 aux = depth 투표 0표(votes 28:0, margin 1.0) +
    140프레임만 존재** — ride_type=DUO 가정이 두 번째 후보를 무조건 aux로
    승격. 행인일 가능성 높음. attribution에 지속성/투표 하한 추가 후보 —
    단 t18 관련 동결 쌍의 호환성 검토 필요.
