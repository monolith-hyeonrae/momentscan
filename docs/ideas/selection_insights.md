# 포트레이트 · 하이라이트 · Likeness — 인사이트 로그

> 살아있는 문서. 이전 논의 맥락은 리셋하고, *확실한 것들*부터 다시 쌓아가며 갱신.
> v0.4 — Likeness 목적(아바타) + 세 출력의 공유 구조(unification) 추가.

---

## 1. 문제

비디오 입력 → *타겟 인물 p*에 대해 세 출력:

- **Likeness** — p의 외형 *불변량* 추출(아바타용) (→ §4)
- **Portrait** — p의 *가장 좋은/특징적* 프레임 선택 (→ §3)
- **Highlight** — 그날의 *추억*을 가장 잘 되살리는 순간 선택 (→ §2)

> Portrait/Highlight = **선택**(어느 순간). Likeness = **추출/파라미터화**(어떤 사람). 종류가 다름.

---

## 2. Highlight의 목적 — 추억 (the WHY)

목적은 **추억**. 한 장으로 *그날 전체가 되살아나야* 한다.
→ **Highlight ≠ 피크 강도.** = *기억 환기력*(에피소드 재구성력). 스릴/피크는 단서의 *한 가닥*.

**회상 단서(추억 차원):** 즐거움/긍정(valence, *구성 요소*) · **함께함(togetherness, 새 축, 단위 = p+동행)** · 장소 정체성(배경 = 내용) · 그날의 나(self ⇒ Likeness 연결) · 스릴(baseline 대비) · 분위기/날씨.
**출력:** 세트는 top-k 아닌 차원 **coverage**.

---

## 3. Portrait의 목적 — PFP 같은 컬렉션 (the WHY)

선택을 *모으면* **PFP 컬렉션 미감** — *개성 넘치고 멋진*, *다양하지만 규칙·균형*.

**버킷이 왜 틀렸나:** 그 미감은 *피사체 분류*가 아니라 **균일 컨테이너 + 자연 변이**에서 온다.
- 규칙·균형 = *제시 방식*(균일 크롭/프레이밍/품질/스타일). 구조는 *틀*에.
- 다양성 = *내용물*(실제 모집단). *공짜*, emergent.
⇒ 버킷 = 옳은 목표, 틀린 메커니즘(#3 실패). 구조는 *내용 분류*가 아니라 *틀 균일화*.
- 개성+멋짐 = 게이트(#4) 생존자 중 *가장 표현적/특징적* 프레임.
- 서브틀티: 실제 변이 ≫ PFP 어휘 → 컨테이너(프레이밍/스타일)가 coherence 주 지렛대.

---

## 4. Likeness의 목적 — 아바타 (the WHY)

이 사람을 *닮은 아바타* 생성용 데이터. (a) 생성모델 conditioning, (b) 3D 아바타에 외형 특성 주입.

**추출 대상:** 골격 기하(눈넓이·눈썹·광대·코·입) → 정규화 랜드마크 → **블렌드셰입**. + 헤어, 의상, **컬러 팔레트**.

**핵심 — 선택이 아니라 추출:** Likeness는 *불변량*(프레임 무관 안정 형태)을 *집계*해 뽑는다. Highlight가 *피크*로 잡는 순간 표정 변이는 Likeness엔 *평균해 없앨 노이즈*. ⇒ Likeness는 *저-magnitude(중립)* 프레임을, Highlight는 *고-magnitude(피크)*를 — 같은 baseline의 **반대 끝**.

---

## 5. 세 출력의 공유 구조 (unification)

**Likeness = 우리가 이미 필요했던 per-person baseline.** (표정 magnitude의 기준 = 그 사람 안정 형태 = Likeness)

세 출력이 *한 substrate*를 공유:
- 공유 토대 = **#4 깨끗-프레임 게이트 + per-person 불변량(= baseline)**
- **Likeness** = 불변량 *추출·파라미터화* (깨끗·중립 프레임 집계)
- **Portrait** = 가장 좋은 *특징적* 깨끗 프레임 *선택*
- **Highlight** = baseline 벗어난 *추억-피크* *선택*
→ 따로가 아니라 *한 파이프라인의 세 면*.

---

## 6. 결정적 제약: curation-free

정교한 큐레이션(라벨·밸런스·카테고리) 불가. **타협 아니라 *옳은* 제약** — 구조(연속·상대·발견된)가 원리적으로 큐레이트 불가. 큐레이션 요구 방법은 자원 무한해도 실패.

---

## 7. 확실한 것들

**#1 분류 아님 (상대 선택).** 내재 아닌 *상대*(거의 같은 프레임 갈림 = 모순). 노이즈 바닥: 큰 격차만 신뢰. → top-set, 확신 비교만, 중간 기권.
**#2 density 아님 (방향).** 전형성 ≠ 품질 → mode 수렴, 비율에 휘둘림. → 판별적 *방향*.
**#3 사전정의 카테고리 아님.** 깔끔함 = "기준→사진" 인공물. 버킷은 강제 분류 → 번짐. → 발견되는 연속 구조, 중간 기권.
**#4 품질 = 논리곱(AND).** 조명∧표정∧포즈∧선명∧비가려짐. 단일 방향 실패(이질적 부정/min/credit assignment 부재). → 요인별 분해(대부분 객관), 어려운 건 표정 한 축.

---

## 8. 공통 뿌리

네 실패 = **이산·절대·사전정의·외부큐레이트 구조를 / 연속·상대·발견된 현실에 강요.**
→ 신호는 *인스턴스 내부-상대*거나 *원본 데이터 고유*, 절대 *사람이 큐레이트 안 함*.

---

## 9. 떠오르는 양성 방향

- **학습 없음(또는 러프)** — 우리 쪽 큐레이션·학습 0에서 시작 가능.
- **내부-상대** — 인스턴스가 자기 레퍼런스. 맥락 자동 보정.
- **표현** — 일반 off-the-shelf. 감정-과제 모델 *피함*.
- **표정 = magnitude**, not 카테고리 — baseline 대비 거리.
- **Likeness** — 깨끗·중립 프레임 *집계* → 골격 기하(랜드마크→블렌드셰입)·팔레트 추출. 헤어/의상은 연속 외형 + 유사도 retrieval(분류 아님).
- **Portrait** — #4 게이트 가지치기 → 생존자 중 *특징적* 프레임 선택 → **균일 크롭/프레이밍/스타일**로 PFP coherence. 게이트 = 품질·일관성 이중 역할.
- **Highlight** — *기억 단서 풍부함*: 동행 co-presence + 장소 가시성 + p 알아봄 + 반응 극단성 + 긍정. 세트 = coverage.

---

## 10. 미해결 / 다음

- **baseline/불변량 추정 (keystone)** — per-person, on-the-fly. *Likeness 그 자체이자* Portrait/Highlight magnitude의 기준. 세 출력의 중심.
- **togetherness 신호** — 동행/아이 co-presence·공동 attention (새 축).
- **장소 정체성 신호** — "여기가 어디" 가시성.
- **Valence** — 강도만 주는 magnitude의 한계. 단 togetherness+장소+공동반응이 긍정으로 기울여 완화.
- **헤어/의상 → 아바타** — 진짜 어려운 전이 문제(분류 아닌 retrieval).
- **균일 컨테이너** — 크롭/프레이밍/스타일 정규화.
- **러프 학습 vs 무학습**, **표현 선택**.
