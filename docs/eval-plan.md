# E-트랙 — 평가 기판 계획 (E1 스키마 = DRAFT, user 검토 대기)

**목적**: 품질의 회귀 그물. R2(특성화 테스트)가 "행동이 안 변했다"를 지킨다면,
E-트랙은 "품질이 안 나빠졌다"를 지킨다 — 이 둘이 깔려야 모든 연구 변경이
"바꾸고 기도"가 아니라 "바꾸고 측정"이 된다. D4(연구→운영 승격)의 품질 절반.

**원리 (2026-07-08 확정)**: 정답은 하나가 아니라 **수용 영역** — 분포의 실체는
"고원+절벽"이며, 고원 안 쌍대 비교는 동전던지기(user 실증). 라벨은 영역을 긋고,
평가는 "선택이 영역 안인가"를 묻고, **사고(incident) = 전 영역 밖 선택**.
portrait 집합-내는 쿼리-조건부 평평(0축 결정) — 집합 안 순위 라벨은 받지 않는다.

## E1 — 회귀 세트 (라벨 스키마 초안)

두 라벨 패스, 두 기준 문서. 같은 클립을 두 번 — 축이 섞이면 라벨러 머릿속에서
매번 다른 비율로 혼합되는 것이 모호성의 원천 중 하나.

### 패스 A — P2 portrait: 수용 집합

전 프레임 라벨은 불가능 → **기계 후보 위 판정 + 놓친 것 추가** 방식:
기계가 admitted 후보(+주변)를 타임라인과 함께 제시, 라벨러는 후보별 수용/거부,
그리고 타임라인 훑기에서 "기계가 안 올렸지만 수용인 프레임"을 추가.

```jsonl
{"pass": "P2", "clip_id": "test_3", "track_id": 0, "intent": "default",
 "accepted": [401, 597, 638], "rejected": [84], "missed_good": [512],
 "worn": {"401": [], "597": [], "638": []},
 "note": "f597 side라도 수용 — 표정이 그 사람다움"}
```

**착용 정책 (확정 2026-07-14, user)**: 마스크/선글라스 착용 컷은 **수용** —
"착용 = 그날의 fashion = 그 사람" 원칙의 P2 일관 적용. 프레임별 `worn` 플래그
기록(예: ["mask"]) — 키오스크/앱이 나중에 다른 정책을 원하면 재라벨 없이 필터.
**집합-내 선택 힌트 = 그날-identity 정합**(벗은-얼굴 선호 하드코딩 금지):
혼합 착용 고객이라도 likeness fashion 판독(sunglasses_frac/mask_frac·worn/
variable)이 그날 identity가 어느 쪽에 가까운지 이미 재고 있음 — frac 높으면
쓴 컷이 대표성 우세일 수 있음(user: "반드시 쓴 장면이 유리한 건 아니지만" —
힌트지 규칙 아님, 실전의 어려운 판단 지점이라 판정 카드+user 동행 대상).

- `intent`: 초기엔 `default`("이 사람을 잘 나타내는 한 장") 하나로 시작 —
  의도 다변화는 C9 preset과 함께 (라벨 재사용을 위해 intent 필드는 지금부터).
- **메트릭**: ①containment = 시스템 선택 ∈ accepted 비율 ②**incident** =
  missed_good 존재(확연히 좋은데 기계 후보에도 없음) 또는 선택 ∈ rejected.

### 패스 B — P3 highlight: 의도별 수용 구간

```jsonl
{"pass": "P3", "clip_id": "test_2", "intent": "serene-glide",
 "intervals": [[41.2, 47.0], [63.5, 66.0]],
 "context_tag": "vista-sea",
 "note": "여유 미소 × 바다·풍력발전기 전경"}
```

- `intent` 슬롯 (**확정 2026-07-14, user**): 3종, 소유 = C9 preset(race981) —
  - `peak-thrill` — 절정 구간의 반응 (비명·환호·집중)
  - `reaction-after` — 절정 직후 리액션 (웃음 터짐·안도)
  - `serene-glide` — **느긋한 활강**: 평온·여유 미소 × 경관 시너지. 자기-컨트롤
    기구의 성향-조건부 탑승 모드(성향별 컨텐츠 분기 축). 구간이 길 수 있고
    라이더에 따라 0개일 수 있음 — 둘 다 스키마가 자연 수용.
  - (boarding-smile은 보류 — 소프트 선호, 라벨 축 아님)
- `context_tag`(선택): 구간의 코스 맥락(예: vista-sea) — miss 진단 시 장면 레인
  탓 vs 얼굴 레인 탓 분해용.
- **메트릭 (확정 2026-07-14)**: ①구간 재현율 — **주 판정 = 모먼트-포함**(세그의
  피크 시점 ∈ 수용 구간; 관대·**길이-불변**) + **병기 = IoU@0.3·@0.5**(문헌 비교축,
  경험 쌓이면 위아래 조정 — 라벨 불변이라 공짜) ②**incident** = 시스템 세그의
  피크가 전 구간 밖. **가변 창 대비(user)**: 현행 6s 고정창이지만 3~10s로 달라질
  수 있음 — 모먼트-포함 판정이라 창 길이가 바뀌어도 라벨·메트릭 재사용 보장
  (방출기 변경은 기존 미결 "창 형태 onset/release"와 합류).

**레인 어텐션 (설계 노트, user 2026-07-14 — 연구는 E1 후):** 맥락이 증거 레인
(main 얼굴·aux 얼굴·배경 경관)의 가중을 동적으로 정한다 — vista가 열리는 순간
전경 가중↑는 동승자 탑승 시 aux 얼굴 가중↑와 **같은 메커니즘**(트랜스포머 어텐션
비유; QD-DETR류 query-dependent representation과 수렴). 코스 프로파일(preset)이
vista 구간을 손-저작(트랙 고정)하고 DTW-by-scene으로 정렬하는 것이 싼 1단.
**정직 예측**: 현행 WHEN(강렬함·드묾·장면변화)은 thrill-형이라 serene-glide
구간을 놓칠 것 — 그 갭의 문서화가 E1의 목적이며, 수리 = intent-조건부 WHEN +
레인 가중.

### 라벨 위생 (2026-07-14 — user 문제 제기: "유사 장면이 네거티브로")

과거 라벨의 모순은 세 메커니즘이었고 새 스키마가 구조적으로 제거: ①고원-강제선택
(쌍대 패자 기록=동전던지기 감독) → 영역-내 선택 없음 ②중복-이유 탈락(커버리지
셋에서 안 골린 것이 네거티브로 보임) → 다양성은 선택 층 소관, 라벨은 수용만
③의도 앨리어싱(암묵 질문이 그날그날 바뀜) → intent 필드가 질문 명시.

- **옛 라벨 수입 규칙(비대칭)**: `output/l2/eval/`의 동결 자산(프레임쌍 168·세그쌍
  75×2·절대 126) 중 **승자 = 약한 수용 후보(새 패스에서 확인)** / **패자 = unknown,
  네거티브 아님**. portrait-v1 절대 라벨은 미수입(기존 결정).
- **라벨 린트**: 유사 장면(임베딩 근접)인데 같은 intent에서 라벨 상충 → 플래그·
  재검토 큐 (모순 = 조용한 독이 아니라 표면화된 diff).
- **재라벨 안정성 프로브**: 씨앗 패스 후 2클립을 날 바꿔 재라벨 → 구간 경계
  일치율 측정 (스키마 안정성을 측정으로 증명).
